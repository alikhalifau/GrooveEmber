# GrooveEmber

GrooveEmber is a cloud-based, auto-scaling platform for high-availability data exchange, leveraging gateway and broker architectures.

GrooveEmber is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- GrooveEmber is a cloud-based, auto-scaling
- platform for high-availability data exchange,
- leveraging gateway and broker architectures

## Technology Stack

- javascript
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/GrooveEmber.git`
2. `cd GrooveEmber`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
